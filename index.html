Telecharger

Installez-la, regardez-la, puis decidez

L'application s'installe sur Windows et fonctionne ensuite sans internet. Elle s'ouvre en decouverte ; votre numero de serie l'active definitivement, sur votre ordinateur, a votre nom.

Windows — 32 bits recommande Fonctionne sur tous les ordinateurs, 32 comme 64 bits. Environ 453 Mo. Windows — 64 bits Un peu plus rapide sur les gros documents. Machines 64 bits uniquement.

Au premier lancement, Windows peut afficher « Editeur inconnu » : cliquez sur Informations complementaires, puis Executer quand meme. Comptez environ 1 Go sur le disque une fois installee.

Questions

Ce qu'on nous demande le plus souvent

Faut-il une connexion internet ?

Seulement une fois, pour activer votre numero de serie. Ensuite la valise fonctionne entierement hors ligne — y compris les simulations.

Sur combien d'ordinateurs puis-je l'installer ?

Un. Votre numero est lie a votre machine. Si vous changez d'ordinateur ou reinstallez Windows, ecrivez-nous : le transfert prend une minute.

Et les mises a jour ?

Les nouveaux contenus de l'annee scolaire en cours sont inclus. L'application vous previent, telecharge et installe seule — quelques megaoctets, pas toute la valise.

Puis-je modifier les documents ?

Oui. L'editeur integre montre la page A4 exactement telle qu'elle s'imprimera, et vos modifications restent chez vous.

Mac ou telephone ?

Pas pour l'instant : l'application est prevue pour Windows. Les documents exportes en PDF, eux, s'ouvrent partout.
